Import a Box Score

Drop a box score PDF from any NJCAA or college site. Both common layouts work: the column style ("Official Football Box Score" with side-by-side tables) and the narrative style (RUSHING: Team - Player 17-82). Every player with production gets a stat line and a suggested efficiency grade. Tick who to log, edit anything, then Log selected.

Evaluation Requests

Everything submitted through the public page at get-evaluated.html. Players, high school coaches, parents, trainers. Triage here: accept turns it into a real prospect you can assign, pass closes it out.

Prospect Market

Every player on the Production Market, JUCO and transfer candidates included, exactly as coaches see it. Price is the latest game grade, change is versus the game before. Built from the Performance log; nothing to enter here.

Recruiting Boards

Every list a program has handed us, plus the Samford receiver board. Pick a board, check guys off as you work them, assign any player or the whole board to a scout.
